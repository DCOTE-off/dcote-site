# Notes

Рабочие заметки по процессу разработки, а не документация продукта.
Документация продукта — в `README.md` и `docs/*.md` уровнем выше.

| Файл                 | Зачем                                                              |
| -------------------- | ------------------------------------------------------------------ |
| `00-process.md`      | Цикл разработки: ветки, коммиты, что делать с отвлечениями         |
| `01-unknown-code.md` | Разбор кода, который писал не я. Что это, как работает, что менять |
| `02-testing.md`      | Как писать тесты с нуля. Текущая инфраструктура и её проблемы      |
| `03-findings.md`     | Найденные баги и недочёты с приоритетами                           |
| `04-roadmap.md`      | Порядок работ и обоснование приоритетов                            |
| `05-tech-debt.md`    | Отложенные решения: роли, хардкод, метрики                         |

## Правила ведения

Заметка живёт до тех пор, пока пункт не закрыт. Закрыл — удали строку или
перенеси в `docs/` как настоящую документацию. Эта папка не должна
превращаться в архив.

`NOTES.md` в корне (в `.gitignore`) — для сиюминутного потока мыслей во время
сессии. Сюда, в `docs/notes/`, попадает только то, что переживёт неделю.
